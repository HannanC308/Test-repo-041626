# Project: Daily Goal & Habit Tracker

A visual grid system helping students build good habits like chores, homework, and drinking water.

## 1. Features
*   **Habit Checklist:** Weekly view (Monday-Sunday) for up to 5 habits.
*   **Streak Tracker:** Displays a fire emoji (🔥) next to habits completed 3+ days in a row.
*   **Daily Reset:** Clears checkboxes automatically at midnight to start a new day.
